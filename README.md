# SoFilNet audio samples

Audio samples for *SoFilNet: Self-Supervised Source-Filter Model of Speech Production*: TIMIT test utterances
(VTR-FORMANTS subset), each original next to its three reconstructions from Table V of the paper.

View the page at `https://<account>.github.io/sofilnet-samples/`.

The page and audio are generated by `make_demo_page.py` in the SoFilNet code repository.
